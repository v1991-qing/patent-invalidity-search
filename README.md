# 专利无效检索 Skill

针对**已授权专利**的无效检索与稳定性分析技能，供 AI Agent 加载使用。

回答一个问题：**这份专利的哪几项权项能被无效掉、用什么证据组合。**

只就证据论证据——目标专利自身的文本缺陷（26.3 / 26.4 / 33 条）不在本技能范围内。

---

## 它解决什么问题

无效检索的难点不在"会不会用数据库"，而在四件事上容易出错：

| 常见问题                                 | 本技能的处理                                       |
| ---------------------------------------- | -------------------------------------------------- |
| 用一个申请日统管全案，忽略部分优先权     | 逐项核对基准日，给出"各权项基准日表"               |
| 把抵触申请当组合文献用，证据链被一击即破 | 明确抵触申请仅限中国申请、仅用于新颖性             |
| 检索求全不求准，堆一堆 A 类文献          | 求准：每条证据落到"覆盖哪些特征、如何拼成完整覆盖" |
| 结论只写"有/无新颖性"，没有可用的论证    | 逐项比对 → 三步法组合 → 专利权人抗辩预演           |

## 能力边界

**处理**：专利法 22.2（新颖性）、22.3（创造性）、22.4（实用性，少见）。

**不处理**：26.3 公开不充分、26.4 得不到支持 / 不清楚、33 修改超范围、9 条重复授权、25 条客体问题。这些靠专利文本自身即可主张，论证结构与证据类理由不同，混写会稀释主攻方向。遇到相关方向只作一句话提示，不展开。

## 安装

技能目录名需与 `SKILL.md` 中的 `name`（`patent-invalidity-search`）保持一致。

## 目录结构

```
.
├── SKILL.md                      # 主文件：定位、范围边界、10 步流程、质量红线
├── confirmation-points.md        # 12 个交互式确认点（A1–A5 / S1–S3 / B1–B4）
└── references/
    ├── search-strategy.md        # E 表四维度、分类号、检索式全表 #1–#18、时间限定、语种补检
    ├── comparison-method.md      # C 表特征分解、证据定级、新颖性判断、三步法、抗辩预演
    └── report-template.md        # 稳定性分析报告标准结构（0–8 章 + 附录）
```

`SKILL.md` 只放决策逻辑，检索式全表和模板放在 `references/` 按需读取，避免主文件过长挤占上下文。

## 工作流

| 阶段   | 步骤                                             |
| ------ | ------------------------------------------------ |
| 定边界 | 1 输入确认 → 2 目标专利分析 → 3 权利要求解释     |
| 检索   | 4 检索要素表与分类号 → 5 按思路铺开 → 6 补充手段 |
| 论证   | 7 证据整理与定级 → 8 逐项比对 → 9 证据组合取舍   |
| 输出   | 10 结论与交付（对话内 Markdown / docx / PDF）    |

第 2–3 步定的是**单一口径**：权项怎么解释、基准日是哪天。这两件事没定死就开检索，后面全部要重来。

## 交互式确认点

技能不会一路闷头跑到底。12 个关键节点会停下来用选择题询问，得到答复再继续——例如目标专利号与权项范围、是否主张过宽限期、检索式是否放行、结论的用途（无效请求 / 谈判 / 应诉）。确认点清单见 `confirmation-points.md`。

## 免责声明

本技能产出的是**基于专利文献检索的技术分析意见，不构成法律意见**，不能替代执业专利代理师或律师的正式意见。无效宣告的最终结果取决于国知局合议组的认定。使用前请核实数据库公开日的准确性。
