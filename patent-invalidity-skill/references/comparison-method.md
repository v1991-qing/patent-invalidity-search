# 特征分解与比对评价方法

## 1. 技术特征分解（C 表）

| 特征 | 内容 | 权利要求 | 说明书依据 |
| ---- | ---- | -------- | ---------- |
| C1.1 | …    | 权1      | [xxxx]     |
| C1.2 | …    | 权1      | [xxxx]     |
| C2.1 | …    | 权2      | [xxxx]     |

规则：

- **编号规则**：`C<权项号>.<序号>`，`C1.1` = 权 1 第 1 个特征；每条独权/从权逐项拆完，权项内连续编号；
- **跨权项重复的特征只在首次出现的权项下编号**，其余括注引用（如 `C1.3（同 C4.2、C5.1）`），避免同一特征被重复计数、虚增区别特征条数；
- **引用多项的从权必须拆成独立分支**。「根据权利要求 1 或 2 所述……」这类写法不是一条权项，而是随引用关系展开的多个独立技术方案。按引用逐条展开、逐条比对，编号在表内加"引用分支"列区分（如 `权3（引权1）`、`权3（引权2）`）。漏掉一个分支就等于漏掉一条无效理由，而实务中专利权人往往正是在某个分支里保留了唯一能存活的方案；
- 区分**步骤/结构限定**与**目的/效果限定**——后者单独标记，比对时按"是否起限定作用"处理：目的或效果限定若不带来结构或步骤变化，相同性判断中不予考虑；反之会虚增区别特征，把本该被破坏的新颖性做成"有区别"；
- 说明书对术语下了明确定义（如具体数值、判定标准）的，单独摘录，作为权项解释素材；**说明书自己下了定义，就必须按该定义解释**——这既是解释规则，也是对抗专利权人宽解释主张最有力的一招：定义段由对方自己撰写，很难再主张相反含义；

## 2. 对比文件定级

**编号一律 `D1、D2…Dn` 连续编号**；法律类别只放在"类别"列用 X/Y/A 表达。编号不带类别含义，改级时按需调整编号与顺序。

**列序**：D 编号 / 公开号 / 申请人 / 公开日 / **要点** / 类别（X·Y·A）/ 涉及特征（C1.1、C1.3…）/ 定级理由 / 关键段落号。

**定级确认（B1）**：交用户确认后锁定并进入评价，锁定后即做 X/Y 类外文文献的中文要点翻译。

表后写"要点解读"：

- **哪些特征属常规**（多篇均公开，用于切分"常规部分"与区别特征）；
- **哪种特征没有一篇文献完全公开**（决定组合能否成立）；
- 哪些从权需几篇组合才能覆盖（组合层数多 → 该从权相对稳，是专利权人的退守点）；

## 3. 新颖性评价（逐篇单独比对）

关键纪律：

- **单独对比原则**：每一项权项分别与每一份文献单独比对，**不得组合**。组合是创造性的事，混进来就是法律错误；
- **"直接的、毫无疑义地确定"标准**：文献必须明确记载该特征，不能靠推理补足；
- **列全部不确定点**：中间态结构是否算完整特征、该工艺条件下能否产生所声称的问题/效果、该文献处理的是否为本案所指的对象。逐条写出，并给使用建议（如"建议作创造性证据，不作新颖性主证据"）。

### 3.1 抵触申请：先判"同样的发明或者实用新型"

抵触申请只能打新颖性，法定要件是"同样的发明或者实用新型"（22.2 第 2 款）。判的是**技术方案是否实质相同**，不看文字相似度；注："同样的发明创造"是第 9 条重复授权的用语，本技能不涉第 9 条，勿混用：

| 情形                                                                                                                             | 结论                                     |
| -------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| 技术方案实质相同（技术手段、所解决的技术问题、预期效果综合判断，不要求逐字一致）；文字表述不同（同义词替换、步骤换序但功能不变） | **构成**抵触申请                         |
| 文字高度相似，但解决的技术问题不同，或手段有实质差别（缺少必要技术特征、参数范围不重叠）                                         | **不构成**，降为非现有技术或背景文献     |
| 仅部分特征重叠                                                                                                                   | **不构成**——部分重叠不够，必须是完整方案 |

上下位概念不当然"构成"：在先申请公开下位、权项为上位 → 构成（下位落入上位）；在先申请公开上位、权项为下位 → 原则上不构成，除非上位公开使该下位"直接、毫无疑义地确定"。

三条判据：

- 比对单元仍是权项级：以目标权项的**全部**技术特征为准，逐特征确认是否被在先申请公开，标准同新颖性——"直接的、毫无疑义地确定"，不得靠推理补足；
- **两份文本都读到全文再判**，尤其不要用摘要判"不同"：摘要常省略关键步骤，容易把"实质相同"误判成"不同"，也会把"实质不同"误判成"相同"；
- 时间要件逐项核：在先申请的**申请日**须早于目标权项基准日，其**公开日**须不早于该基准日（基准日可能是逐项不同的，见 SKILL 一节）。

## 4. 创造性评价（三步法）

每条证据组合按固定格式：

1. **最接近的现有技术**：公开特征最多、同领域同申请人的优先。**优先同申请人文献**是实务技巧而非条文——结合动机天然成立，还可能构成自认；
2. **区别特征与实际解决的技术问题**：基于区别特征在方案中的作用**重新确定**，**不得照抄说明书自述问题**。这是防止事后诸葛亮的核心机制：先知道答案再倒推"问题显而易见"，是审查意见和无效决定里都很常见的错误；
3. **是否显而易见**，按区别类型分五种应对：
   - **顺序类**：找同领域"该工序先后顺序属标准做法"的文献；
   - **参数类**：多文献端点/区间拼合 + "属常规选择、说明书未述特殊效果"论证；
   - **目的类**：列"出于该目的采用后续处理属常规思路"的动机文献（注明段落号）；
   - **结构类**：该结构已被公开 + 该结构只是常见结构或仅做了细微改动；
   - **领域类**：本领域技术人员有无动机去该领域找（技术问题的共通性、功能一致性）、领域跨度（同机理还是同结构）、转用需改动多少（有无阻碍因素），结论写成"可以结合 / 难以结合"。

**组合成立的三个要件**：①每篇证据自身公开了对应特征；②时间上都是现有技术（抵触申请不得入组合）；③有结合动机。第③项最容易被忽略，也最容易被攻破——"两篇都公开了这些特征"并不等于"应当结合"。

**"属公知常识"最好有书证，不能只写结论。** 主张某区别特征属公知常识、常规选择或常规实验手段（参数类、目的类论证里最常用），须以**教科书、技术手册、工具书、国家或行业标准**佐证，注明书名（含版次）、页码、原文表述，作为证据附上。专利文献的一般性记载只能作辅助，不能单独支撑"显而易见"——某篇专利写了不等于本领域普遍知晓，这是合议组最常直接驳回的一类论证。手边确实没有书证时，把该主张写成"倾向性意见，尚需补充公知常识性证据"，并列入补充证据方向，**不得作为组合成立的主要理由**。

## 5. 抗辩预演

| 抗辩点             | 专利权人依据                      | 我方反驳要点                                                 | 评估 |
| ------------------ | --------------------------------- | ------------------------------------------------------------ | ---- |
| 问题由其发现       | 前人未意识到"这一技术问题"        | 这一技术问题对应的需求已存在；已有文献教导该现象/问题        |      |
| 预料不到的效果     | "出人意料"                        | 效果是相同步骤的固有效果；只有一个数据点、无对比             |      |
| 反向教导           | 文献称该结构/方法带来了不好的效果 | 文献同时记载该条件下不致损害；只有单篇文献，难以称作反向教导 |      |
| 审查已考虑过某文献 | 审查引文                          | 该文献属新证据或新理由                                       |      |

程序性抗辩：**证据形式要件**（公开日证明、外文证据的中文译文是否提交、公证认证是否齐备）。

## 6. 结论等级用语（统一）

- 稳定性：**高 / 中 / 低**（"高"= 难以被无效，即被宣告无效的风险低），报告开头须注明方向；
- 新颖性：**未破坏 / 存疑（注明理由与文献） / 被破坏**；
- 结论矩阵按**权项 × 稳定性**逐项展开；每格填：稳定性等级 + 主证据 D 编号 + 组合层数。

## 7. 结论确定性（B4）

- **完整口径（默认）**：所有结论含存疑项一并写入；存疑项标"存疑"+原因（检索盲区 / 文献不确定点 / 解释取向未定 / 证据形式待核），不隐藏不确定性；
- **保守口径**：仅用户主动选择时启用——正文只写有把握的结论，存疑项集中附录；
- 两种口径下，"未检到≠不存在"的局限声明都必须保留；
- "能不能无效"与"有多大概率无效"分开写：前者是法律判断（特征是否被公开、组合是否有启示），后者还取决于合议组对解释的采纳、证据形式要件、口审表现。合并成一句"胜算较大"是不专业的。
