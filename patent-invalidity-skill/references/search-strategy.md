# 无效检索策略

数据库两类来源：**自有账号库优先**；无账号用免费库（Espacenet、Google Patents、CNIPA、PATENTSCOPE）。示例语法以 PatSnap 为主：`TACD`=标题+摘要+权利要求+全文，`TAC`=标题+摘要+权利要求，`AN`=申请人，`IN`=发明人，`APD`=申请日，`PBD`=公开日，`AUTHORITY`=受理局。换库时等效转换，并注明语法差异。

## 1. 检索要素表（E 表）

### 1.1 检索词四维度

| 维度         | 含义                             | 词例方向                                               |
| ------------ | -------------------------------- | ------------------------------------------------------ |
| **技术领域** | 权项所属分支、应用载体           | 领域名称、上下游产品、材料体系、应用场景词             |
| **技术问题** | 权项方案要解决的问题             | 缺陷词（劣化、损耗、失效）、需求词（提高、降低、避免） |
| **技术手段** | 权项记载的结构、步骤、工艺、参数 | 部件名、工序名、工艺参数、装置名                       |
| **技术效果** | 权项或说明书声称的效果           | 效果参数、测试指标、性能描述词                         |

操作要求：

- **专利权人的自造词、特殊用语必须配通用同义词**——权项用词往往是本案特有的，现有技术不会这么写，这是无效检索最典型的漏检成因；
- 技术问题、技术效果维度的词，是问题导向式检索式（`#12`、`#18`）的词源。

## 2. 分类号策略

- 主分类：目标专利 IPC 全部 + 相邻分类；
- 降噪排除：列出排除分类写入 `NOT`；
- 跨领域检索反向操作：排除本领域分类号，去其他分支找同机理方案——很多组合证据就藏在隔壁领域（转用是否成立的论证在三步法第 3 步内完成，见 `comparison-method.md` §4）。

## 4. 时间限定

- **现有技术式统一加 `PBD:[19000101 TO 截止日]`，截止日 = 基准日 − 1 天（无优先权或优先权不成立时基准日即申请日）。这不是可选项**：加了上限，检索范围才与"现有技术"的法律定义对齐，报告里"检索范围"一句才站得住；**存在部分优先权时**，按各权项基准日分别设截止日——要么分别跑式，要么按最晚基准日跑一次再逐篇核对公开日并按权项分派，后者须在备注里写明取舍理由；
- **`#8`、`#9` 例外，`PBD` 上限放宽到检索执行日（不截在截止日）**——它们要的正是截止日之后公开的那部分（抵触申请、非现有技术）。这两式命中后必须逐篇分类，不得混入现有技术；
- `#8` 必须限 `AUTHORITY:(CN)`：抵触申请只限中国申请（含 PCT 进入中国），外国同族或在先申请只能算非现有技术；

| 情形               | 处理                                                                                                                |

| 韩文原文字段返回 0 | `AUTHORITY:(KR)` + 英文词补检                                                                                       |
| 西文原文字段不出   | `AUTHORITY:(ES OR MX OR AR OR CL OR CO OR PE OR BR OR PT)` + 英文词补检                                             |
| 日文               | 原文汉字/片假名双词表；同族中文公开可作译文参考——若其公开日早于基准日，其本身即现有技术，可直接引为对比文件         |
| 德文/法文          | 原文词表；注意合成词通配（Ladungseinfang*、Sperrschicht*）；法文多词短语用引号整体检索（"recuit thermique rapide"） |

## 6. 补充手段

1. **引证追溯**：目标专利审查引文 + 同族 ISR 引文。审查员筛过的引文命中效率远高于自己跑式；引文间同族关系必须标注（同一发明的多份公开文本只算一篇证据）。
2. **审查档案调取**：不只找证据，更找**禁止反悔**——授权过程中放弃了什么、陈述了什么，直接决定权项解释的边界；解释口径一定，检索词与比对标准随之确定。
3. **申请人/发明人追踪**：目标专利权人及其前身、主要竞对、核心发明人名单。
4. **公开时间分类**：命中文献按公开时间分三类——①现有技术（公开日 ≤ 截止日）；②抵触申请（申请日 ≤ 截止日、公开日 > 截止日、**且为中国申请**）；③非现有技术（不构成现有技术、也不构成抵触申请：公开日不早于基准日的**外国**在先申请，以及申请日与公开日均晚于基准日的申请；仅作技术背景/译文参考）。**逐篇写明判定理由与中国/非中国依据**。
5. **跨领域补充**：本领域证据不足以支撑创造性或需补强某从权时，排除本领域 IPC 去相邻领域找同机理方案；转用是否成立的论证写进三步法第 3 步，不单列章节。

## 7. 命中处理

- **命中量异常必问（S2）**：单条 >500 或 <5，报告后由用户选收窄/扩词/换角度/跳过，决定记入备注列；
- **新角度必问（S3）**：不得自行追加，按序编号或子编号，在备注列注明"用户确认追加"；
- **外文文献处理**：X/Y 类做中文要点翻译，A 类只引段落号；
- 每条记录：编号 / 数据库 / **检索式与字段语法（原样可重跑）** / 语种 / 执行日期 / 思路角度 / **覆盖目标（权项 + 特征）** / 要点 / 命中数 / 备注；
- 宽泛式命中多时抽样核对并记录抽样方式；
- 关键文献回**全文**核对段落号，**禁止只看摘要下结论**；
- 法律状态：注明数据源与查询日期。
