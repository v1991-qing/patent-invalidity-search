# 稳定性分析报告模板（无效专用）

交付格式默认**Markdown**，可选 docx / PDF。MD 也可以直接按下列结构在对话内交付；选 PDF 时经 HTML 中转排版（封面：标题 + 目标专利号 + 日期 → 正文 → 页脚注明"基于专利文献检索的技术分析意见，不构成法律意见"）。docx 按 office 文档流程转换，**保持本模板的章节编号与表格结构**。

**交付时核心证据在对话内以"对比文件证据清单"形式先行呈现**，完整版为稳定性分析报告。

```
专利稳定性分析报告

0 报告头
  分析对象（公开号 + 名称 + 授权公告日）、专利权人、申请号/申请日、
  优先权日（及优先权是否成立）、**部分优先权时给"各权项基准日表"**
  （权项 / 基准日 / 依据 / 是否享优先权）、
  **是否主张 24 条宽限期（主张则注明类型与
  首次公开日，并说明检索范围是否相应扣除）**、法律状态（来源 + 查询日期 +
  无效/异议记录）、预计届满日、领域与主分类号、数据库、
  现有技术截止日（各权项基准日不一致时分别列出）、检索执行日、
  检索式数量（全表）、
  对比文件数量（按 X/Y/A 分组）、报告日期
  声明：基于专利文献检索的技术分析意见，不构成法律意见

1 结论摘要
  1.1 总体判断（一段话：哪些权项被覆盖、主证据组合）
  1.2 逐项结论表
      权项 / 关键特征 / 结论（已公开·部分公开·组合公开·未检到）/
      主证据（D 编号 + 段落号）/ 组合层数 / 稳定性等级（高＝难以被无效）

2 检索概况
  2.1 目的与范围（用途、时间界限、数据库）
  2.2 检索要素与分类号（E 表四维度 + 主分类 + 降噪排除）
  2.3 检索式与命中（全表 #1–#18 及子编号：
      编号 / 思路 / 数据库 / 检索式 / 语种 / 执行日期 /
      覆盖目标（权项+特征）/ 要点 / 命中数 / 备注）
  2.4 补充检索（引证追溯 / 申请人发明人）

3 目标专利分析
  3.1 著录与法律状态（含年费、同族、既往无效/异议）
      3.1.1 各权项基准日表（逐项核对优先权：权项 / 基准日 / 依据 /
            是否享优先权；全部同日时可省略，改为一行说明）
  3.2 方案概述（背景 / 问题 / 方案 / 机理）
  3.3 权利要求与技术特征（C1.1–Cn.m：特征 / 权项；
      多项从权按引用分支展开，标注"权3（引权1）"等）
  3.4 问题与特征对应（技术问题 Q1–Qm 与对应特征的映射）
  3.5 审查、同族与审查档案（同族清单、审查引文、ISR 引文、
      与 EP/US 授权文本差别、审查过程中的限缩与陈述）

4 权利要求解释
  4.1 解释原则与方法（通读全文取最合理含义）
  4.2 歧义措辞解释表（措辞 / 确定的含义 / 依据段号 / 对检索与结论的影响）
  4.3 待用户核对清单（B3 记录：用户是否改口径、改了哪几处、影响范围）
  4.4 与平行程序的口径协调（存在侵权/行政程序时：本报告口径、该程序既有
      主张、差异及理由、被对方援引的风险；无平行程序时写明"无"）

5 对比文件
  5.1 一览表（D1–Dn：编号 / 公开号 / 申请人 / 公开日 / 类别 X·Y·A /
      涉及特征 / 要点）
  5.2 定级表（D 编号 / 公开号 / 申请人 / 公开日 / 要点 /
      类别 / 涉及特征 / 定级理由 / 关键段落号）+ 要点解读
      
6 逐项技术特征比对（每特征一小节）
  格式：各文献相关段落号列举 → 小结（已公开 / 部分公开 / 未检到 +
  一句话判断 + 不确定性提示）

7 新颖性与创造性评价
  7.1 新颖性
  7.2 独立权利要求创造性（每条组合三步法：最接近文献 → 区别特征与
      重新确定的技术问题 → 技术启示）
  7.3 从属权利要求（权项 / 引用关系 / 附加特征 / 评价 / 稳定性等级）
      —— 引用多项的从权（"根据权 1 或 2 所述"）按引用分支逐条评价，
         不得合并成一行；分支未覆盖的须单列"未覆盖分支"
  7.4 专利权人可能的抗辩与反驳（抗辩点 / 依据 / 我方反驳要点 ）
      含程序性抗辩：证据形式要件、译文

8 结论与建议
  8.1 评估矩阵（权项 × 稳定性等级 × 主证据 D 编号 × 组合层数）
  8.2 主推组合与备选组合（组合链 / 覆盖特征 / 层数 / 各权项杀伤力 / 优劣势）
  8.3 分用途建议
      · 无效宣告：**请求形态**（全部无效 / 部分无效、请求宣告的权项清单、
        权项间引用关系如何拆）、主证据组合、从权补充证据、同一理由下的
        备选组合与其他权项、补充证据方向、审查档案调取、口审应对准备、
        外文证据译文提交安排（举证期限内）
      · 稳定性评估/许可谈判：可作筹码的权项、专利权人最可能退守的权项
        及预备组合、谈判节奏建议
      · 规避设计：权项覆盖宽度、规避代价、声明未做 FTO 分析
  8.4 局限与声明
      数据库范围、非专利文献未检、语言盲区、审查档案是否取得、
      法律状态来源与查询日期、附图处理方式、
      参数确认情况（哪些为默认值）、"未检到≠不存在"、
      **本报告未评价目标专利的文本缺陷（26.3/26.4/33）与 9 条重复授权**、
      "本报告不构成法律意见"

附录 A 专利号清单（目标 / X·Y 类 / A 类 / 译文参考，分号分隔可直接批量导入）
附录 B 检索式全表（字段同 2.3）
```

## 填写要求

- 第 1.2 节逐项结论表是全文最常被直接引用的部分，**必须每条都带 D 编号与段落号**，不能只写"已被 D3 公开"；
- 第 4 章必须在第 5、7 章之前（**解释定不下来，比对就没有基准**）；章号一动，SKILL.md 与 confirmation-points.md 内的引用全部要跟改；
- **不设文本缺陷章节**：26.3 / 26.4 / 33、9 条重复授权不在本报告范围，**既不设章节、也不给结论**；最多在结论摘要里一句话提示"另可考虑 XX 问题，本报告未展开"，并在 8.4 局限中声明；
- 快速筛查级报告：删去 7.4、8.2、8.3，并在报告头注明降级原因与由此产生的局限。
