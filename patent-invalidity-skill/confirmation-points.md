# 无效检索 · 交互式确认点清单

> 用途：执行中遇到下列关键点，**停下来用选择题询问**，得到答复再继续。  
> 状态：12 项（A1–A5 启动 5 项、S1–S3 检索 3 项、B1–B4 评价输出 4 项）已定稿。  
> 总原则：**影响结论方向的问题必问，只影响操作细节的按默认值执行并事后注明**；一律选择题（附"其他"自由填写）。

| #  | 确认点  | 选项与规则                                                                                                | 跳过时默认       |
| -- | ---- | ---------------------------------------------------------------------------------------------------- | ----------- |
| A1 | 权项聚焦 | 填空式：留空 = 全部；填权项号 = 聚焦。聚焦时重点权项做完整评价，其余仅快速筛查并注明                                                        | 全部逐项评价      |
| A2 | 检索深度 | **默认完整**，快速筛查（约 10 条）仅在用户明确要求时使用。                                                                    | 完整          |
| A3 | 数据库  | ①自有账号库（PatSnap/incoPat/智慧芽等）；②免费公开库（Espacenet、Google Patents、CNIPA、PATENTSCOPE）。报告须注明实际使用的库，覆盖差异写入局限 | 有账号→①；无账号→② |

## S. 检索执行阶段（触发时单独问）

| #  | 确认点        | 选项与规则                                                                                                                                                             |
| -- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| S1 | 检索要素表确认    | **仅完整检索必确认**。确认表展示：E1–Em 中英词表、主分类 + 降噪排除分类、时间界限（现有技术截止日 = 基准日 − 1 天；**存在部分优先权时逐项列出各权项的基准日与截止日**；抵触申请窗口单列）。按**技术领域/技术问题/技术手段/技术效果**四维度检查覆盖。用户可增删词、加语种、调分类。快速筛查跳过本项 |
| S2 | 单条检索式命中量异常 | 触发：单条 >500 或 <5。报告异常（检索式、命中数、原因分析）后由用户选：①收窄；②扩词；③换角度（申请人/分类号/引证追溯）；④跳过该式继续。选择与理由记入备注列                                                                             |
| S3 | 中途新增检索角度   | 不得自行追加。先报告发现（是什么、为何值得追加、预计价值），用户选：①追加；②暂缓随同思路后续式一起检；③记录但暂不检索；④放弃。                                                                                                 |

## B. 评价与输出阶段

| #  | 确认点      | 选项与规则                                                                                                                                                                                                                                          |
| -- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| B1 | 对比文件定级确认 | 时机：检索完成、逐篇核对全文后，进入评价**之前**。内容：定级表（D 编号 / 公开号 / 申请人 / 公开日 / **要点（前置）** / 类别 X·Y·A / 涉及特征 / 定级理由 / 关键段落号）+ 要点解读。用户可改级、增删文献、要求补检；确认后锁定，进入评价                                                                                                       |
| B2 | 证据组合取舍   | 时机：逐项比对完成、写结论**之前**。存在多个可行组合时列组合对比表（组合链 / 覆盖特征 / 组合层数 / 各权项杀伤力 / 优劣势），用户选定主推 + 备选；仅一个组合时告知"无备选"并说明理由。                                                                                                                                          |
| B3 | 权利要求解释核对 | 时机：解释做完、检索**之前或同步**；结论成型后再复核一次。内容：歧义措辞清单（措辞 / 确定的含义 / 依据段号 / 对检索与结论的影响），用户在清单上确认或改口径。**用户改口径时，按新含义重做该处相关的检索与比对，并在报告中记录改口径的经过与影响范围**。**存在平行侵权/行政程序时**，本项同时核对口径是否与该程序的既有主张一致；不一致须由用户选择：统一口径 / 保留差异并写入报告风险说明。跳过时按 SKILL 自定口径执行，清单随报告呈现（对应报告第 4 章） |
| B4 | 结论口径     | 默认**完整口径**：所有结论含存疑项一并写入，标"存疑"+原因（检索盲区 / 文献不确定点 / 解释取向未定 / 证据形式待核）。**保守口径**（用户主动选）：正文只写有把握的结论，存疑项集中附录。两种口径下"未检到≠不存在"的声明都必须保留                                                                                                                    |

## 询问节奏总则

1. **启动时**：一张多选确认表收集 A1–A5，附"跳过"选项；
2. **检索前**：B3 权项解释核对（口径定不下来检索就是白跑；S1 检索要素表确认亦在检索前，属执行前置检查）；
3. **检索中**：S 类触发时单独问；
4. **评价前**：B1；**写结论前**：B2；**交付前**：B4；
5. 用户的选择与跳过情况，在报告末"参数确认情况"一节逐条注明。
6. **范围守卫**：本技能只处理证据类理由（22.2 / 22.3 / 22.4）。用户提出 26.3、26.4、33、9 条重复授权、25 条客体问题时，**一句话说明超出范围**（"这属文本缺陷/范围比对，本报告不评价"），提示另起任务，不在本报告内展开论证、不给成案可能性评级。
